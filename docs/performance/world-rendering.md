# 固定布局、流式显示与 LOD

云场默认覆盖 24 × 24 千米，格宽约 850 米，占用率 0.72，种子为 128。当前布局得到 563 个固定位置，上限 768 个。默认相机附近通常只实例化几十朵，具体数量随高度、位置和实例包围半径变化。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| RenderDistance | 3000 米 | 完整显示到此距离 |
| FadeDistance | 1200 米 | 此后的渐隐宽度 |
| PreloadMargin | 600 米 | 完全透明边界以外的准备距离 |
| RevealSeconds | 1.2 秒 | 实例创建后的时间渐入 |

布局位置先存为轻量描述。加载检查使用云体包围半径扩大范围，每帧最多创建 8 个实例。超出加载范围、包围半径与额外 400 米回差后释放节点。位置描述始终保留，返回同一区域恢复相同位置。运行时取消水平回绕和云心位移，三层顶点与表面纹理动画继续。

云的片元着色器按云心距离和入场进度进行平滑 Alpha 混合，使用 depth_prepass_alpha 让完整显示的部分参与深度预通道。距离超过 4.2 千米后完全透明，节点在更远处才释放。移动进出可见范围时会连续改变覆盖率，首次加载或远距离跳转则叠加入场淡入。

flow_cloud_lod.res 从原始网格数组生成，基础顶点与 AABB 保持原样，增加 11 档索引 LOD。Godot 根据屏幕投影自动选级。原版演示使用 flow_cloud_mesh.res 供比对。

每个可见实例共享网格、材质和纹理。形变包围盒按当前材质的最大位移计算。生成、卸载、返回和相机瞬移应检查固定位置、无重复实例、渐入连续性与 GPU 几何量。当前 Main 的玩家相机远裁剪面为 10 千米，覆盖云的渐隐与预加载区域。

地图范围可通过 CoverageSize 扩展，超出配置地图边界后属于云场以外。改变云材质的顶点幅度时生成器会更新形变余量。
